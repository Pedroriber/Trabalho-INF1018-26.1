--------------------------------------------------------------
1. DESCRIÇÃO GERAL
--------------------------------------------------------------

O trabalho consiste na implementação da função cria_func, que
recebe o endereço de uma função f, um array de descritores de
parâmetros (DescParam), o número de parâmetros e um vetor de
bytes (codigo[]). A função gera dinamicamente, no vetor codigo,
o código de máquina x86-64 de uma nova função que chama f com
os parâmetros descritos, podendo amarrá-los a valores fixos
(FIX), a variáveis (IND) ou repassá-los diretamente (PARAM).

--------------------------------------------------------------
2. ESTRATÉGIA DE IMPLEMENTAÇÃO
--------------------------------------------------------------

A implementação foi feita de forma gradual, testando cada
funcionalidade antes de avançar para a próxima;
 - Passo 1: Implementação do PARAM
 - Passo 2: Implementação do FIX
 - Passo 3: Implementação do IND
 - Passo 4: Implementação do PTR_PAR
 
O código gerado segue a estrutura:

  - Prólogo: push %rbp / mov %rsp,%rbp / and $-16,%rsp
    (alinhamento de 16 bytes necessário para funções de biblioteca)

  - Salvamento dos PARAM na pilha (push %rdi/%rsi/%rdx),
    para evitar que instruções FIX/IND sobrescrevam os valores
    recebidos pela nova função antes de repassá-los.

  - Geração das instruções para cada parâmetro, em ordem inversa,
    populando os registradores corretos (rdi, rsi, rdx):
      * PARAM: pop do valor salvo na pilha para o registrador certo
      * FIX INT_PAR: mov $constante, %edi/%esi/%edx (5 bytes)
      * FIX PTR_PAR: movabs $endereço, %rdi/%rsi/%rdx (10 bytes)
      * IND INT_PAR: movabs $end_var, %rax + mov (%rax), %edi/%esi/%edx
      * IND PTR_PAR: movabs $end_var, %rax + mov (%rax), %rdi/%rsi/%rdx

  - Chamada indireta: movabs $endereço_de_f, %rax + call *%rax
    (necessário pois f pode estar em qualquer endereço de 64 bits,
    como funções da libc, impossibilitando o call relativo de 32 bits)

  - Epílogo: leave / ret
